# 家庭日競賽計分板

單一 HTML 檔案，放上 GitHub Pages 就能用。資料存在 GitHub Gist，多人同時開著同一個網址，任何人保存後其他人會收到更新提示。

---

## 一、部署（約 5 分鐘）

**1. 建立資料 Gist**

到 [gist.github.com](https://gist.github.com)：

- 檔名：`scoreboard.json`
- 內容：貼上本專案的 `scoreboard.json`（或先填 `{}`）
- 按 **Create secret gist**

網址長這樣 `https://gist.github.com/yourname/`**`a1b2c3d4e5f6...`**，最後那串就是 **Gist ID**。

Secret gist 不會被搜尋到，但知道網址的人可以讀 —— 這對現場計分板剛好合適。

**2. 建立寫入權杖**

GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token：

- 有效期限：設到活動結束後幾天
- 權限：**只勾 `gist`**
- 產生後複製 `ghp_...`

**只有需要改分數的工作人員才需要這把權杖。** 觀眾、主管、投影機那台不用填，自動是唯讀。

**3. 上架**

把 `index.html` 推到一個 repo，Settings → Pages → Source 選 `main` / `root`，等一分鐘就會有 `https://你的帳號.github.io/repo名/`。

**4. 各裝置設定**

開啟網址 → 分頁「連線與備份」→ 填 Gist ID、權杖（計分人員才填）、你的名字 → 按「儲存設定並連線」→ 第一次請按「用目前資料建立雲端初始版本」。

> 權杖只存在該台裝置的瀏覽器 localStorage，不會寫進網頁原始碼、不會上傳到 Gist、不會進 git 紀錄。

## 二、同步怎麼運作

| 機制 | 行為 |
| --- | --- |
| **更新** | 從雲端抓最新資料蓋掉畫面（有未保存變更時會先問你） |
| **保存** | 上傳到雲端，版本號 +1，記錄時間與保存者 |
| **自動保存** | 開啟後，改動停止 1.5 秒自動上傳 —— 現場登記名次建議開著 |
| **更新提醒** | 每 10 秒（唯讀裝置 45 秒）背景檢查，發現別人保存了新版本，畫面下方跳出提示條 |
| **衝突保護** | 保存前先比對版本號。若雲端已被別人改過，不會直接覆蓋，而是讓你選「放棄我的變更並載入」或「以我的為準覆蓋」 |
| **離線** | 資料同時寫入本機快取，斷網仍可操作，恢復後按保存即可 |

右上角永遠顯示：最後更新時間 · 保存者 · 版本號 · 連線燈號。

## 三、現場操作動線

**賽前**
1. 「隊伍總名冊」建好所有可能出現的組別，填預設隊長與聯繫方式
2. 進每個競賽分頁的「參賽隊伍」，挑出本場要上場的隊伍、排好順序、填本場隊長
3. 「賽事設定」確認各項目權重與名次積分表
4. 匯出一份 JSON 備份

**賽中** —— 一個項目結束後
1. 開該競賽分頁，找到項目卡片
2. 用綠色的 **快速登錄** 色塊，**依抵達順序點隊伍**，系統自動給 1、2、3…
3. 點錯再點一次取消，或按「重新編號」把空缺補起來
4. 有人中止競賽就勾「中止」，自動以該項目最後一名積分計點
5. 自動保存會直接上傳，其他裝置幾秒內看到

**配合紙本板子**
- 每張計分板上方都有自己的順序列，用 ◀ ▶ 即時搬動欄位，對齊該場板子的組別順序
- 「依名次排列」可一鍵切成排行榜視角，切回「自訂順序」不會動到你排好的順序
- 「大字模式」給投影機或平板遠看用
- 「列印」會去掉所有按鈕，只留乾淨表格

## 四、隊伍名冊：每場競賽各自一份

三層結構，避免不同場次的隊伍混在一起：

| 層級 | 在哪裡維護 | 用途 |
| --- | --- | --- |
| **隊伍總名冊** | 「隊伍總名冊」分頁 | 所有可能出現的組別，以及預設隊長／聯繫方式。改名字在這裡改，全站同步 |
| **參賽隊伍** | 各競賽分頁最上方 | 這場競賽誰上場、欄位順序、本場隊長與聯繫方式 |
| **項目層** | 各項目的成績表 | 該項目臨時換人帶隊時覆寫 |

隊長／聯繫方式由下往上繼承：項目層有填就用項目層，沒填用本場的，再沒填用總名冊的預設值。欄位的灰色提示文字就是繼承來的值。

- 鐵人三項全員 8 隊、趣味競賽一只有 4 隊報名 —— 兩邊互不影響，各自算名次、各自 DNF 以自己的隊數計最後一名
- 從某場競賽「移除」隊伍只清掉該場成績；從總名冊「刪除」才會全站移除
- 在競賽分頁按「新增隊伍」會同時加進總名冊，省一道手續
- 「綜合總冠軍」自動收錄至少參加過一場的隊伍，沒參加的場次顯示「—」不計分

## 五、計分規則（已內建，可改）

**鐵人三項**（加權模式，權重合計 100%）

| 項目 | 權重 | 名次積分 |
| --- | --- | --- |
| 極限衝鋒 | 30% | 100 / 85 / 70 / 60 / 55 / 50 / 40 / 35 |
| 力拔山河 | 30% | 100 / 85 / 70 / 60 / 55 / 55 / 55 / 55 |
| 1200 公尺大隊接力 | 40% | 100 / 85 / 70 / 60 / 55 / 50 / 40 / 35 |

同分時以 1200 公尺大隊接力勝負為依據（在「賽事設定」可改成別的項目）。

**趣味競賽**（累加模式）三項各取前三名 100 / 85 / 70，直接相加。

要新增趣味競賽四、五，或改成 5 / 3 / 1 分制，都在「賽事設定」裡改，不用動程式碼。

---

## 六、換掉儲存後端

`index.html` 裡的 `Store` 物件只有 `read()` 和 `write()` 兩個方法在跟雲端說話。要換成 Supabase、Firebase、JSONBin 或自家 API，改那兩個函式即可，其餘邏輯不用動。
